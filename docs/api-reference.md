# API reference

The service scores raw loan applications with the saved blend. Interactive documentation is generated by
FastAPI at `/docs` (Swagger UI) and the machine-readable schema at `/openapi.json`.

## Run it

```bash
python scripts/train_model.py                     # needs the competition data in data/
uvicorn hcdr.api.app:app                          # model path: output/model_bundle.joblib or $HCDR_MODEL_PATH
```

The model is loaded once at startup. If the artifact is missing or invalid the service still starts, `/health`
reports `degraded`, and the inference routes return `503`.

!!! danger "Only load artifacts you created"
    The model file is a joblib (pickle) file. Loading an untrusted file can execute arbitrary code.

## Endpoints

| Method | Path | Success | Errors |
|---|---|---|---|
| GET | `/health` | `200` `{"status": "ok" \| "degraded", "model_loaded": bool}` | none |
| GET | `/model-info` | `200` model metadata (versions, model names, row/feature counts, training time) | `503` no model |
| POST | `/predict` | `200` `{"default_probability": float}` | `422` invalid input, `503` no model |
| POST | `/predict/batch` | `200` `{"count": int, "predictions": [...]}` in request order | `422` (empty, over 1000 records, invalid), `503` |

Unexpected failures return `500` with a generic message. Responses never include file paths, stack traces or
the submitted values; request payloads are not logged.

## Request body

`POST /predict` takes one object with the 32 raw application columns (see
[Data and features](data-and-features.md#raw-input-columns)); `POST /predict/batch` takes
`{"records": [ ... ]}`.

* Unknown fields are rejected, including `TARGET` and `SK_ID_CURR`.
* Optional (may be omitted or `null`, scored as missing): `OCCUPATION_TYPE`, `AMT_ANNUITY`, `AMT_GOODS_PRICE`,
  `OWN_CAR_AGE`, `CNT_FAM_MEMBERS`, `EXT_SOURCE_1`–`3`, `DAYS_LAST_PHONE_CHANGE`, `AMT_REQ_CREDIT_BUREAU_*`.
* Constraints: `AMT_INCOME_TOTAL > 0`, `AMT_CREDIT > 0`, `DAYS_BIRTH < 0`, `EXT_SOURCE_*` in [0, 1],
  `FLAG_*` in {0, 1}, `REGION_RATING_CLIENT` in 1–3, counts and amounts non-negative, no `NaN`/`Infinity`.
* Category values are free text; a value not seen in training is treated as missing (the same as in the batch
  pipeline).

```bash
curl -s -X POST http://127.0.0.1:8000/predict -H "Content-Type: application/json" -d @application.json
```

## Interpreting the response

`default_probability` is the blend's score for `TARGET = 1`. It is validated as a ranking score by ROC-AUC and is
not shown to be calibrated. Do not use it for an operational credit decision without independent validation.

!!! note "Production readiness"
    The service runs locally and is tested. It has no authentication, rate limiting, monitoring or model
    versioning beyond the metadata in the artifact, so it is not production-ready as is.
