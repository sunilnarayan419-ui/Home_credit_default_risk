# Data

The competition files are **not** included in this repository (competition data must not be redistributed).

Place them here before running anything:

```
data/
├── train.csv
├── test.csv
└── sample_submission.csv
```

(An `input/` sub-folder, as in the original competition ZIP, also works: `data/input/train.csv`, ...)

Use a different location with the environment variable `HCDR_DATA_DIR=/path/to/folder` or the `--data-dir` flag of every script.
